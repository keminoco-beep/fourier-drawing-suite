# 改进评估文档：笔触算法（禁止后处理）的候选方案与通过/放弃判据

日期：2026-10-19　｜　对象：`structpaint` 纯笔触绘画算法（chibi 鲸鱼娘，源图 421×412）
约束（用户要求）：**不使用区域裁剪、边缘后处理、图像级锐化等后处理手段**；所有改动只发生在
"已存在的算法组件"内：结构分类、笔触生成、笔宽/笔刷策略、RL 奖励与动作、文档拟合契约、
训练目标与评估口径。每个方案先评估，**无效即放弃，有效才保留**。

---

## 0. 一句话背景

上一轮诊断已确认边缘糊的四个算法内主因：
① 宽笔（中位 37px@2048，源线宽≈9.7px）占 68%，2044/2406 是 round 宽笔；
② 89% 笔画 alpha<1 半透明叠加；
③ RL/训练目标为局部 MAE（最优解=条件均值=糊），动作空间在 421 决策分辨率下 ±4px（≈±19px@2048）；
④ 类别分配失衡（61 shade / 1 flat），shade 策略为 airbrush×1.8 宽笔。
（区域裁剪被排除，不再作为方案。）

## 2. 评估协议（每个方案必须同协议跑）

1. **固定输入**：`assets/out/user_chibi/chibi_whale.png`；固定结构构建（同一 coverage/decompose 参数）；
   固定随机种子集合（至少 2 个 seed）。
2. **训练预算**：每方案短训 **≤ 40 分钟**（约 30–40 轮，单进程 60–90s/轮）；并行 2 个 seed。
   不沿用消耗 5h 的生产训练，避免"调参看运气"。
3. **评估口径**：训练时 doc 契约固定为 **target_resolution=2048**（与交付一致）、评估渲染
   **1024 + supersample=2**；最终指标用 **R=2048、SS1** 渲染（与基线相同）。
4. **报告指标**（全部自动落 JSON）：
   - `psnr`, `ssim`（对原图）
   - `edge_sharp_ratio`（≥ 参考边 5% 梯度像素；越接近 1 越好）
   - `err_near_edge_frac`（3px 内误差占比；越低越好）
   - `width_median_px`, `frac_width_gt_30px`（笔宽分布）
   - `alpha_lt_099_frac`（半透明笔占比）
   - `class_counts`（每类笔数）
   - 局部三联图（头发/眼睛/裙边三个 600×600 裁切）供目视复核
5. **每方案产出**：`eval/<方案ID>/metrics.json` + `report.md`（含目视截图），并记录在 §6 表格。

## 3. 通过 / 放弃判据（硬门槛）

方案必须**同时满足**：

1. `PSNR ≥ baseline_psnr − 0.05`（不显著退步）；
2. `SSIM ≥ baseline_ssim − 0.002`；
3. 主目标二选一（至少一条）：
   - `edge_sharp_ratio` 相对基线 **≥ +10%**（0.225 → ≥0.248），或
   - `err_near_edge_frac` 相对基线 **下降 ≥ 10%**（0.37 → ≤0.333）；
4. 笔宽分布向目标移动：`width_median_px` 下降或 `frac_width_gt_30px` 下降（两者至少一项）；
5. 目视三联图中，边界/五官比基线明显更清晰（不允许"变糊换 PSNR"）。

**放弃条件**（任一）：PSNR 掉 >0.05 且边缘指标无改善；或边缘指标改善但 PSNR 掉 >0.3；
或 2 个 seed 结果方向不一致（不稳定）。

## 4. 候选改进方案（全部为算法内改动）

### A. 笔宽/笔型标定（`structpaint` 笔宽策略）
- **假设**：宽笔占主导是糊的主因；把笔宽按"源测量尺度 + 结构类别"标定后，边缘锐度应提升。
- **改动点**：`_fill_strokes_for_region` 的宽度公式（`DT*2*width_scale`）；按类设上限
  （例如 @421：flat/shade 上限 12px、detail 6px、line 4px；@2048 对应 58/29/19px）；删除 1.8 倍宽策略候选；
  或在 `POLICY_CANDIDATES` 中把 shade 的 width_scale 限制到 ≤1.2。
- **预期**：`frac_width_gt_30px` 68%→<30%；edge_sharp +10–30%；PSNR 可能 ±0.1。
- **风险**：宽笔减少 → 铺色变慢/漏底；用同预算下轮数衡量。

### B. 类别分配修正（`structpaint` 分类阈值 + 笔型分配）
- **假设**：61 shade/1 flat 的错误分配让 airbrush 宽笔铺了所有内部区域；应把"平色区"判成 flat
  用不透明圆头平涂、只有真正渐变区判 shade、小结构判 detail。
- **改动点**：`build_structure` 中 `col_std` 阈值（当前 0.06）、区域面积规则；`POLICY_CANDIDATES`
  中 flat 用 `basic_round_hard`、shade 用窄笔/低 alpha、detail 用 marker 小笔。
- **预期**：flat 笔数 18→数百；shade 宽笔大幅减少；边缘/结构更清晰（与 A 互补）。
- **风险**：flat 平涂笔若仍宽，边界仍糊；需与 A 联动。

### C. 边缘笔生成（现有 line stroke 算法的增强，非后处理）
- **假设**：当前 line 笔只有 145 条且来自中轴分支；沿参考线稿/区域边界生成窄的"沿边笔"
  （线笔/窄 ink 笔）能直接定义边界，替代宽笔平均色。
- **改动点**：`structpaint._line_strokes_for_struct`：从 decompose 的线稿分支与区域多边形边界
  生成窄笔（宽 = 测量线宽×0.8–1.1，颜色=暗线色），并让它们 layer 最高；不修改渲染结果图。
- **预期**：edge_sharp_ratio 明显提升（这是"用更细的笔重新画"而非后处理）。
- **风险**：线稿重建不准会画出错位黑线（目视否决条件）。

### D. RL 奖励与动作空间（替换局部 MAE 目标）
- **假设**：MAE 最优=平均色；把奖励改成"局部误差下降 + 边缘梯度/SSIM 项 + 越边惩罚"，
  并收缩动作空间，能抑制"宽笔挪过边界换 MAE"。
- **改动点**：`stroke_rl_render.run_stroke_rl_search` 的候选评分与接受判据；
  动作幅度：位置 ±4px→±1px（421 空间）、宽 ×0.8–1.2→×0.9–1.1；越边惩罚 = 若笔触 bbox 内
  参考梯度高且笔色与两侧颜色差异大则给负奖励。
- **预期**：边缘处笔触更贴合（近边误差占比下降）；PSNR 可能略降但 SSIM/边缘改善。
- **风险**：奖励权重敏感；需要 2–3 组权重小扫。

### E. 半透明/覆盖规范（两遍铺色架构内调整）
- **假设**：89% alpha<1 的宽笔叠加平均色是糊的放大器；底色层 alpha→1，纹理层只在内部且低 alpha，
  并限制同一位置覆盖次数（通过笔触生成阶段避免重叠，而非渲染后处理）。
- **改动点**：`_fill_strokes_for_region` 两遍参数（base alpha=1、texture alpha≤0.2）；
  `brushfit` 的 alpha floors（若有）；笔刷 preset alpha 曲线。
- **预期**：边界混色减少、拉普拉斯方差下降；edge_sharp +5–15%。
- **风险**：变"硬边/平涂"可能损失质感，PSNR 或 SSIM 略降；属于审美取舍，以目视+指标共同判定。

### F. 训练-交付口径统一（训练配置算法内修正）
- **假设**：训练在 768/SS1、doc 契约 768 下选笔，与 2048 交付不一致，宽笔糊在训练中不可见。
- **改动点**：`train_loop.py` 的 `--eval-res` 用 1024、`--eval-ss 2`；`structdoc.build_doc_from_strokes`
  的 `cfg.target_resolution` 用最终渲染 R（2048）；`FBSConfig.contract()` 相应 epsilon。
- **预期**：训练目标与交付一致；后续 A–E 的收益才不会被"训练看不到"抵消。单测：契约字段正确。
- **风险**：单轮成本上升 ~2–3×（渲染更贵）；短训预算相应减少轮数，用 seed 稳定性衡量。

### G. 训练目标增加边缘项（训练循环选择准则）
- **假设**：当前 J = PSNR − 笔数/线段惩罚，仍然只看 PSNR；把 `SSIM`/边缘锐度作为次目标，
  进化/剪枝时用 `J2 = PSNR + λs·SSIM + λe·edge_sharp_ratio` 选择，可保留锐利候选。
- **改动点**：`trainloop._psnr_ssim`（已算 SSIM）→ 选择与剪枝分数；`w_strokes/w_segments` 保持低权重。
- **预期**：在同等 PSNR 下选出边缘更清晰的候选（配合 A/C/D 收益放大）。
- **风险**：SSIM 对糊不敏感；需先用基线候选验证排序合理性。

## 6. 结果记录表（2026-10-19 实测）

### 6.1 前置 F（训练-交付口径统一）——**保留**

- 改动：文档 Fourier 契约按最终 R=2048 拟合；训练评估 1024（SS1）；笔触宽度上限/策略覆盖参数化。
- 40 分钟短训（17–21 轮）即达到 **PSNR 18.65–18.67 / SSIM 0.825–0.829**（旧流程需 5h 才到 18.71），
  训练效率显著提升；边缘指标与原基线相当（edge 0.218–0.222 vs 0.225）。
- **判定：保留（作为后续实验的统一口径）**。注意：F 本身不解决糊，只是让后续改动"训练看得见"。

### 6.3 C（沿边窄笔，v1）——**放弃**

- 实现：区域多边形边界采样 + 图像梯度 ≥p75 过滤 → 窄 ink 笔。
- 实测只生成 **14 条**边缘笔（区域多边形多数落在低梯度处，过滤后几乎为空），
  2048 指标与 base 完全一致（PSNR 16.721、edge 0.2106 不变）→ **无效果，放弃**。
- 备注：若要重做 C，应改为"图像梯度脊线骨架"生成（而不是区域多边形边界），但这属于新算法，
  按"无效就放弃"原则本轮不继续。

## 7. 非目标（明确不做）

- 任何图像级后处理：区域 mask 裁剪、边缘锐化/反锐化、超分、着色、修复等；
- 引入外部模型/权重（不引入新的大模型）；
- 修改渲染器语义来"作弊"（如把宽笔在边缘处人为收窄）——所有改动必须发生在
  笔触生成/笔宽/笔刷/奖励/训练目标/拟合契约这些已有算法组件内。
