# 边缘糊根因诊断（2026-10-19，停止训练后复盘）

对象：五进程训练收敛后的当前 best（`train_loop_9h_w2`，训练口径 PSNR 18.773 / SSIM 0.750；R=2048 渲染口径
PSNR 18.711 / SSIM 0.828）。诊断产物：`edge_diagnosis.json`、`edge_diagnosis_cmp.png`、
`example_refit2048_R2048.png`。

## 一句话结论

**边缘糊不是渲染器或分辨率不够，而是"宽笔占绝对主导 + 半透明多次叠加 + MAE 目标鼓励平均色 +
笔触未按区域裁剪"四件事叠加的结果；Fourier 拟合精度只是次要因素（实测重拟合只 +0.13dB，边缘锐度几乎不变）。**

## 根因排序

1. **笔触尺度/类型失衡（主因）**：宽笔（中位 37px@2048，是源线宽 4 倍）占 68%，且 2044/2406 是 round 宽笔；
   宽笔圆头跨过边界，颜色又取区域均值 → 边界被平均色抹平。结构层类别分配极端倾斜：
   contour 分区分出 61 个 shade、36 detail、只有 1 个 flat，UCB 又给 shade 选了
   `basic_airbrush, width_scale=1.8` —— 直接把"内部铺色"做成宽糊笔。
2. **半透明多次叠加**：89% 笔画 alpha<1（默认两遍铺色 + RL 调 alpha），宽笔叠加使边界处
   颜色变成多次混合 → 进一步糊。
3. **目标函数/接受判据是局部 MAE**：MSE/MAE 的最优解是条件均值（经典结论：PSNR 优化必然偏糊）；
   RL 连续动作在 **421 决策空间**允许 ±4px 位移、宽 ×0.8–1.2，到 2048 尺度就是 **±19px 位移**、
   宽 ±20% —— 把宽笔挪过边界换 MAE 下降，训练会接受。
4. **笔触不带区域裁剪**：`structdoc.strokes_to_elements` 把所有笔的 `region_id` 写成 **-1**，
   渲染器无法把笔触 clip 回它所属的区域 mask → 宽笔/变异笔可以越界画到邻区。
5. **训练/交付口径不一致（次要但相关）**：训练评估 768 + SS1、文档契约 768，而交付渲染 2048；
   768 口径下宽笔的糊不明显，等于奖励了"低分辨率糊面"。
6. **Fourier 拟合精度（非主因，已验证）**：按 2048 重拟合只 +0.13dB、边缘锐度无实质变化。

## 修复建议（按优先级，全部是算法层的）

1. **区域裁剪**：笔触保留 `region_id` + 区域 mask，渲染时按 mask 裁剪（宽笔只在区域内；边缘自然由 mask 收边）。
   这是最直接解决"越界糊"的一步。
2. **笔宽按源测量标定 + 分层策略**：引入测量（survey 的线宽/区域尺度）做上限；宽笔只做内部平涂，
   边缘 2–3px 与结构处强制使用**沿边窄笔/线笔**；增加 detail/line 笔占比（当前 145/2406 太少）。
3. **损失函数加边缘项**：从局部 MAE 改成 `ΔMAE + λg·Δ梯度/SSIM + λe·越边惩罚`；
   RL 动作空间按最终分辨率收紧（421 空间 ±1px，宽度 ±10%），或对"跨越参考边"的动作一票否决。
4. **铺色/半透明规范**：底色层 alpha 用 1.0（不叠加）；纹理笔只允许画在区域内部且 alpha∈[0.1,0.25]；
   限制同一像素被 >2 笔覆盖。
5. **训练口径 = 交付口径**：doc 契约按最终 R（2048）拟合；评估至少 1024+SS2，不要用 768/SS1 选笔。
6. **生成"边缘笔"**：从线稿/Canny/区域边界直接生成沿边窄笔触，让边缘由明确的细笔定义，
   而不是靠宽笔的内外平均去逼近。

## 复现方式

- 诊断脚本逻辑：读 best fbs/笔触 → 计算渲染 PSNR/SSIM、edge sharpness、Laplacian 比、误差-边缘距离分桶、
  笔宽/alpha/层分布 → 用 2048 契约重拟合同批笔触再渲染对比。
- 输出：`assets/out/user_chibi/edge_diagnosis.json`、`edge_diagnosis_cmp.png`（参考/当前/重拟合三联局部图）、
  `example_refit2048_R2048.png`。
