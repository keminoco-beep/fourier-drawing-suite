# 能力边界与降级策略

> 本文回答三个问题：**什么图能用、什么图会被拒绝、被降级时你会看到什么**。
> 判定阈值以 `scripts/fbs_core/preprocess.py` 的实现为准；本文的数字是实现契约，
> 修改它们必须同步本文与验收用例（T7/T8/T9/T10）。
> 错误码/警告码清单与 `CONTRACT.md` §9 保持同步（单一事实来源）。
> 实现/验证状态见 `references/requirements_traceability.md`。

---

## 1. 一句话定位

`fourier-brushstroke` 是**「位图 → 矢量笔触 → 位图」的往返复刻工具**，不是生成工具。
它把一张已存在的图分解成「中轴笔画 + 傅里叶系数 + 逐 t 画笔属性」，
再从 `.fbs` 在任意分辨率重建。**它不会让画面内容变好**，只改变表示与绘制方式。

## 2. 输入格式支持矩阵

| 格式 | 支持级别 | 说明 |
|---|---|---|
| PNG | ✅ 一等 | alpha / 调色板 / 16bit 均支持（16bit 右移归一化到 8bit） |
| JPEG | ✅ 一等 | 无 alpha；JPEG 块效应会被当作细节，必要时先提高 `denoise_sigma` |
| WEBP | ✅ 支持 | 动图取首帧 + `W_MULTIFRAME` |
| BMP | ✅ 支持 | |
| GIF | ⚠️ 降级 | 取首帧 + `W_MULTIFRAME` |
| TIFF | ⚠️ 降级 | 多页取首页 + `W_MULTIFRAME`；其他模式转 RGB 后处理 |
| SVG / PDF | ❌ 拒绝 | 本身即矢量，无需复刻；`E_INPUT_FORMAT` 并提示直接使用矢量文件 |
| 未知/损坏文件 | ❌ 拒绝 | `E_INPUT_FORMAT` / `E_INPUT_CORRUPT`，不尝试修复 |

**统一归一化目标**：`RGBA8`（4 通道 uint8）。Stage 0 必须处理 Pillow 模式：
`RGB` `RGBA` `L` `LA` `P` `PA` `CMYK` `YCbCr` `I` `I;16` `F` `1`，
并把原始模式记入 `source.mode`，用于回写与溯源。

**其他输入约束**：

| 项 | 规则 |
|---|---|
| 最小尺寸 | 长边 < 32 px → `E_INPUT_TOO_SMALL` 拒绝 |
| 最大像素 | `max_pixels`（默认 4,000,000）超限 → 等比降采样 + `W_DOWNSCALED`，**不拒绝** |
| 非 ASCII 路径 | ✅ 必须支持（中文路径/文件名是一等用例） |
| EXIF 方向 | 自动 `exif_transpose` 校正 |
| 完全透明 / 无可见内容 | `E_INPUT_TRANSPARENT` 拒绝 |
| 全黑 / 全白 / 纯色 | 特殊路径：不出无意义笔画，记录基色 + `W_SOLID_COLOR` |
| 外部网络 | **零依赖**：全流程断网可跑通（A4 验收项） |

## 3. 图像分类判据（Stage 0）

分类是**全局策略开关**，决定后续分解路径与预期质量。v2 分五类：

| 类别 | 判定特征（可测量） | 预期表现 |
|---|---|---|
| `lineart` 线稿 / 签名 / 手写 | 低色彩数、**平均饱和度低**、边缘密度高、笔画细、背景干净 | ⭐ 最佳场景（中轴≈真实中心线） |
| `flat_art` 扁平插画 / 图标 / Logo | 色彩数少、区域边界清晰、边缘为硬跳变 | ✅ 良好（区域填充 + 中轴分支） |
| `illustration` 彩色插画 / 柔光插画 | 颜色数中等、有区域也有渐变 | ⚠️ 良好~中等，笔画数多、体积大 |
| `gradient` 渐变图 | 颜色连续、无明显硬边、噪声水平低 | ⚠️ 降级：中轴退化，warning |
| `photo` 照片 / 实拍 | 唯一色数极高、颜色熵高、噪声水平高、无稳定中轴 | ❌ **明确拒绝**（D5），见 §4 |

**可测量特征**（`preprocess.measure_features()` 实际测量并写入 `image_class.evidence`，
全部是统计量，不含类别先验）：

| 特征 | 计算方式 | 用途 |
|---|---|---|
| `unique_colors` | RGB 唯一色数（超过 100 万像素按步长采样，控制开销） | 区分平涂图与照片 |
| `entropy_bits` | 颜色直方图香农熵 | 照片高、平涂低 |
| `edge_density` | 灰度 Sobel 幅值均值 | 整体边缘强度 |
| `hard_edge_frac` | 梯度幅值 > 0.12 的像素占比 | 区分硬边（线稿/图标）与渐变 |
| `mean_saturation` / `colorful_frac` | `(max−min)/max` 的均值 / 占比>0.25 的比例 | **把黑白线稿与彩色插画分开**（唯一色数对 JPEG 灰阶线稿失效） |
| `noise_level` | 3×3 均值残差的 MAD 估 σ（×1.4826×255） | **把平滑渐变与照片分开**（渐变噪声≈0，早年因此被误判为照片） |
| `flat_frac` | 局部 std < 2 的像素占比 | 平坦区比例，辅助区分渐变/照片 |
| `visible_frac` | alpha > 0.5 的像素占比 | 可见内容比例 |

**分类规则（判定顺序固定；阈值为当前实现值，以 `preprocess.py` 为准）**：

| 类别 | 规则（全部特征都满足才命中） |
|---|---|
| `photo`（拒绝） | `unique ≥ 4096` **且** `entropy ≥ 6.0` **且** `noise ≥ 1.5` **且** `flat_frac < 0.6` |
| `lineart` | `mean_saturation ≤ 0.12` **且** `hard_edge_frac ≥ 0.008` **且** `colorful_frac ≤ 0.03` |
| `flat_art` | `unique < 512` **且** `hard_edge_frac ≤ 0.08` |
| `gradient` | `unique ≥ 2048` **且** `noise ≤ 0.8` **且** `flat_frac ≥ 0.85` **且** `hard_edge_frac ≤ 0.02` |
| `illustration` | 以上都不命中（兜底） |

> 纪律：① **多特征联合判定**，禁止单特征路由（G3 类错误——旧版曾因"唯一色数 < 512"把
> JPEG 灰阶线稿误判为彩插，笔画爆到上限）；② 每一类都要有对应测试用例（T1/T2/T3/T6/T7/T8/T9）；
> ③ 阈值是可测量统计量上的判据，改动必须重新校准并同步本表。

### 3.1 分类原则：宁可说清，不要硬画

- 分类结果为 `photo` → **拒绝**（§4），不是"尽力而为"，且**不可绕过**。
- 分类为 `gradient` → 允许处理，但会在 `warnings` 中说明"中轴退化、结果可能为斑块"
  （降级码随契约同步；当前契约码表见 `CONTRACT.md` §9）。
- `--force-class` 可覆盖 **非 photo** 类别（`lineart` / `flat_art` / `illustration` / `gradient`），
  用于排障与已知类型，并记录 `W_FORCE_CLASS`；**photo 拒绝对所有路径生效**。v2 不提供 `--allow-photo`。
- 分类结果与全部特征实测值会写入 `.fbs` 的 `image_class`，供排障与追溯。

## 4. 照片类输入：明确拒绝（设计决策 D5）

### 4.1 判定即拒绝

检测为 `photo` 时：

1. **明确拒绝**，不产出 `.fbs`（抛 `E_PHOTO_DEFERRED`）；
2. 错误信息**附实测判定依据**（唯一色数、颜色熵、噪声水平、平坦区占比的实际数值），让用户理解为何拒绝；
3. 给出可执行的替代建议（§4.3）；
4. **退出码非 0**，并写入日志。

### 4.2 技术理由

本流水线依赖两个前提：**① 能分出有意义的区域；② 区域存在稳定中轴**。照片令两者同时失效：

- 对照片做颜色量化，得到成百上千个**锯齿状、互不相邻的碎片**，不对应任何真实物体；
- 对碎片求中轴，得到**噪声骨架**，不属于任何"笔触"；
- 结果：笔画数轻松过万、`.fbs` 体积远大于原图、重建结果是一团斑块噪声。

中轴法（D4）对照片**没有任何有效路径**。该结论与算力无关，增加参数不会改变结果。

### 4.3 替代建议（写入错误信息）

- 先做插画化 / 海报化 / 色阶量化（外部工具），再输入本 skill；
- 若目标是矢量线稿，先用边缘检测或描线工具提取线稿；
- 若需要照片级矢量化，本 skill 不是合适工具（见评估报告 §4）。

### 4.4 不提供越权开关

v2 **不提供 `--allow-photo`**。既然暂缓支持，就不应该留一个会稳定产出垃圾结果、
且消耗大量时间与磁盘的入口。未来真正实现照片支持时再一并引入。

**未来扩展前置条件**：Stage 1 需具备面向连续色调的区域划分能力（当前中轴法不具备）。

## 5. 能力上限（不承诺的部分）

以下**不是 bug，是已界定的能力边界**（详见 `references/requirements_traceability.md` 的"未承诺"节）：

| 边界 | 说明 |
|---|---|
| **不追求比 PNG/JPEG 更小的体积** | 硬边内容下傅里叶表示天然大于折线（旧版实测 5.1–54.9 倍），体积目标已放弃 |
| **不保证任意分辨率都清晰** | 同一 `.fbs` 在 `2R` 渲染会出现可见振铃——**不是 bug**：N 的语义绑定在 `target_resolution` 上。要 `2R` 清晰需以 `2R` 重新生成 |
| **不保证细密黑白线稿的保真** | 大量 1–3px 细线蛛网 + 粗填充耦合在同一连通区域时，圆盘并集需要数千条几何精确的细笔画，误差随笔画数累积（旧版在复杂黑白线稿上只有 ~15 dB，并已定位为表示法固有边界）。**当前实现不承诺此类图的高保真**，输出会带 warning |
| **SVG 是互通格式，不是保真格式** | SVG 无法原生表达变宽笔画，导出时离散分段或 stamp 填充，体积大、精度低于 `.fbs` 原生渲染 |
| **照片、写实场景** | 拒绝，见 §4 |
| **内容生成 / 风格迁移 / 超分 / 修复** | 非目标，不做 |
| **GUI** | 非目标，首版为命令行 + 库 |
| **R9（元素拆解 + 图层 + 每层一次 FFT 生成新图）** | **用户已明确搁置**（算力/数据量过大），不要主动重启 |
| 语义图层（"脸/头发/眼睛"） | 不提供。`layer` 是**绘制顺序 / 覆盖关系**，不是语义分组（语义化属 R9 范畴） |
| 多帧动图 / 逐帧动画 | 只取首帧 |
| 外部网络 | 零依赖（也是 A4 验收项） |

## 6. 降级与警告码表

**任何降级都不得静默**：必须写入 `.fbs` 的 `warnings`（`[{"code","message","severity"}]`）
并在 CLI 输出中可见。码表与 `CONTRACT.md` §9 一致（新增码必须同时改契约、本表与验收项）：

| 警告码 | 触发条件 | 用户应理解的后果 |
|---|---|---|
| `W_DOWNSCALED` | 像素数 > `max_pixels` | 已等比降采样，精度按新尺寸计 |
| `W_MULTIFRAME` | GIF / 多页 TIFF | 只处理首帧 |
| `W_SOLID_COLOR` | 纯色 / 无有效前景 | 不出笔画，仅记录基色 |
| `W_PRUNED` | 中轴剪枝移除分支 | 移除了毛刺分支，尖角可能受影响 |
| `W_SHORT_BRANCHES` | 短分支被丢弃（含计数） | 细碎细节可能缺失 |
| `W_SMALL_REGIONS` | 小区域被吸收/丢弃 | 极小色块被合并 |
| `W_MAX_CURVES` | 笔画数超 `max_curves` | 按长度降序截断；必须报告丢弃数量 |
| `W_GAP_BRIDGED` | 虚线碎段在分支图上被桥接 | 断线被接回；不影响其余图像 |
| `W_N_CLIPPED` | 请求/需要的 N > `resample_points/2-2`（Nyquist） | 已钳制到采样上限，再增大 N 无效果 |
| `W_COLOR_FIELD_OFF` | 区域颜色场被关闭或不可用（契约保留码） | 区域退化为单色，渐变细节丢失 |
| `W_ONE_STROKE_TRAVEL` | 一笔画存在抬笔/travel 段（契约保留码） | 视频中可见不落墨的移动段 |
| `W_ONE_STROKE_N` | 一笔画谐波数被 Nyquist/`max_fft` 钳制，或未达目标 | 一笔画精度或圆数低于请求值 |
| `W_FILL_SKIPPED` | region_fill 缺少显式 `poly`，填充被跳过 | 该区域填充缺失（宁缺勿凑，不填碎片） |
| `W_BRUSH_STYLE` | `stroke.brush.style` 索引非法，回退默认笔刷 | 该笔画外观可能与预期不同；必须排查 `.fbs` |
| `W_BRUSH_LENGTH_MISMATCH` | 属性采样数组长度与几何不一致，已重采样恢复 | 已自动修复，但暗示上游数据异常 |
| `W_BRUSH_COLOR_SHAPE` | 颜色/笔形采样非法，已回退 | 该笔画颜色或笔形可能不符合预期 |
| `W_GEOMETRY_SKIP` | 单条曲线几何退化/傅里叶拟合失败被跳过 | 该笔画缺失（不代表其余笔画失败）；原因必须可查 |
| `W_VIDEO_FPS_RAISED` | 帧数不足以覆盖全部作画步骤 | 已自动提高 fps，时长仍保持 target 秒数 ±5% |
| `W_VIDEO_STEPS` | 一笔画文档缺少 `step_spans` | 按单一连续笔画处理，无法区分作画步骤 |
| `W_GAP_BRIDGED` | 轮廓追踪失败回退中轴 / 分支图桥接接回缺口 | 断线被接回或走降级路径；不影响其余图像 |
| `W_SVG_APPROX` | 导出 SVG | SVG 为互通格式，精度低于原生 `.fbs` 渲染 |
| `W_FORCE_CLASS` | 使用了 `--force-class` 强制分类 | 分类被人工覆盖，结果仅供排障参考 |
| `W_UNKNOWN` | 兜底（未知警告被转入日志时） | 表示有未分类的告警，应上报 |

> 实现级新增码（如 `W_FORCE_CLASS` / `W_GEOMETRY_SKIP` / `W_FILL_SKIPPED` / `W_VIDEO_STEPS`）
> 必须同步登记到 `CONTRACT.md` §9；本文与契约不一致时以契约为准并修正本文。
> 标"契约保留码"者已在契约定义、当前实现尚未检索到触发点。

> 纪律：`W_*` 不得只出现于 stdout；上限/循环保护被触发时**必须**产生对应警告，
> 不允许"截断后看起来很干净"。实现/验收状态见 `references/requirements_traceability.md`。

| 内部异常（真正的 bug） | 带堆栈的错误信息，不吞异常 | — | 非 0 |

## 照片输入（D5）与实验通道

默认：照片类输入拒绝（`E_PHOTO_DEFERRED`），附实测特征与替代建议——无稳定区域/中轴，
按区域+中轴分解会退化成上万条噪声笔画。

实验/目标表示：`--painterly` 启用**纯笔触绘画**（一串傅里叶曲线 + 随时间 t 的画笔属性，
无填充/面片）。lenna R=1024 实测：5168 笔、0 填充，PSNR 22.93 / SSIM 0.67，60s 逐笔作画视频；
`*.brush_timeline.json` 是可编辑的作画时间轴。默认合同与验收仍按"照片延期"执行；
`--mesh`（A-GMesh）保留为高保真近似实验，不属于绘画过程表示。

## 笔刷库（F25）

`brushlib.py` 按现代绘图软件分类安装了 20 个笔刷预设（Basic/Pencils/Inking/Markers/
Dry Painting/Chalk·Pastel·Charcoal/Wet Painting/Watercolors/Airbrush/Spray），
笔形内核 10 种（round/soft/marker/bristle/chalk/spatter/airbrush/pencil/watercolor/ink）。
它们只影响**画笔属性**（笔形、尺寸、透明度、抖动、压力），不引入贴图/填充/面片；
完整参数表见 `references/brush_library.md`，渲染样本见 `brush_catalog.png`。
