## 3. 方法

### 3.1 文件筛选（只读）

| 类别 | 数量 | 处理 |
|---|---:|---|
| `._*` AppleDouble 元数据 | 121 | 跳过（不打开） |
| 静态图 webp / png / jpg | 107 / 7 / 3 = **117** | 剔除 6 张包装图后 **111** 张入统计 |
| 包装图（stem 含 `title` / 以 `qq` 开头） | 6 | 跳过（标题、横幅、截图） |
| 动画 GIF 预览 372×560 | 4 | 跳过（非正稿） |
| `info.txt` | 1 | 跳过 |

> 用户口述“117 张 webp”，实测 117 张**静态图**（其中 107 张 webp），格式口径差异已写入分析文档。

### 3.2 指标

- 内存中 LANCZOS 缩到最长边 512 px，测量后立即释放；不写缓存。
- 亮度 Rec.709；饱和度 HSV；背景取外围 6% 边框的中位 RGB。
- Sobel 3×3（归一化），弱边 >0.10、强边 >0.25；ink mask = `luma<0.45`。
- 线宽 = ink mask 行/列游程直方图 p50/p90，按分析尺度换算到 R512/R1024。
- k-means：numpy 手写、k-means++、固定 seed；k=5 RGB、k=3 灰度。
- 直方图每图等权；k-means 像素加权。随机性全部由固定 seed 驱动。

### 3.3 复跑

```powershell
$PY = "<python>"
& $PY poc\style_stats\analyze_refs.py
& $PY poc\style_stats\analyze_refs.py --src "<other-dir>" --out "<out-dir>"
```

已验证：两次运行 `style_stats.json` 除 `generated_at` 外逐字段相等。

## 5. `mono_ink` 参数（摘要）

| 项 | 取值 |
|---|---|
| 画布 | 3:5 竖幅，`#FEFDFD` 背景；R256 154×256 / R512 307×512 / R1024 614×1024 |
| 调色板 | `paper #FEFDFD` / `haze #D0CECE` / `mid #A4A2A2` / `shadow #686566` / `ink #060505`（仅 5 阶） |
| 笔刷 | contour `ink_gpen`、hairline `ink_fineliner`、accent `ink_brush_rough`、fill `basic_round_hard`；可选 `marker_alcohol`/`spatter_brush` |
| 线宽 | hairline `0.0025*S`、contour `round(0.005*S*2)/2`、accent `0.010*S`（S=min(W,H)） |
| 墨量 | ink 像素 0.03–0.17；纸白 0.50–0.85；暗部 0.02–0.10 |
| 对比 | RMS 0.16–0.30；平均亮度 0.76–0.94；p05≤0.35；p50 0.85–0.97 |
| 色彩 | S_mean≤0.03；灰像素≥0.97；无彩色强调 |
| 填充 | 纸白→haze→mid→shadow→ink 线→ink 重音；平涂、不渐变、每个 fill 有轮廓 |

参数同时以 JSON 形式写入 `style_rubric.json` 的 `mono_ink` 段，供 WP-N 直接读取；未改 `style_packs.json`（属 WP-N 写盘范围）。

## 6. 评测 rubric

| 维度 | 权重 | 及格 | 自动检查示例 |
|---|---:|---:|---|
| 结构 | 0.25 | 70 | 主体匹配、数量/位置、比例、构图平衡、图层顺序、不溢出 |
| 风格 | 0.30 | 70 | 单色、5 阶调色板保真、纸白背景、墨量、边缘密度、线宽、对比度 |
| 文字 | 0.15 | 60 | 文本完全一致、缺字、位置、对比度、字号行距 |
| 技术 | 0.20 | **85** | 编译/渲染 100%、seed 确定性、R256 中位≤3 s、PNG 完整、0 error |
| 多样性 | 0.10 | 70 | 20 prompt 计划去重≥18、主体/类别覆盖、构图/参数分布 |

- PASS≥75，EXCELLENT≥85；fatal gate 失败直接 0。
- Fatal：编译/渲染失败、未捕获异常、`mono_ink` 彩色面积>1%、缺字/tofu、输出含参考图像素。
- benchmark 目标：compile/render 1.00、style pass≥0.80、plan 去重≥0.90、R256 中位≤3 s。
- 所有检查基于标量区间；**不做**与参考图的像素/嵌入相似度比较。

## 7. 局限与风险

1. 单作者、非随机集合；阈值只描述该集合，不能外推为“所有黑白漫画”。
2. 指标是像素级代理：Sobel 受抗锯齿/压缩影响；游程线宽混入发束与大 fills。
3. 分析统一缩到 512 px；绝对线宽需按比例换算（已给 R512/R1024 表）。
4. 背景用边框中位数，满幅构图可能偏差（本集合背景纯白，影响有限）。
5. rubric 阈值未经人类 MOS 校准；首次 WP-N benchmark 后建议按实际渲染分布微调一次风格阈值。
6. 成人向内容仅参与全局像素统计，未进入任何 prompt/文档图片；评测 prompt 集必须避开成人主题。
7. `style_rubric.json` 是新增 `assets/eval/` 目录；若 WP-N 的 `prompts_20.jsonl` 尚未落地，rubric 中路径先行声明、不阻塞。
