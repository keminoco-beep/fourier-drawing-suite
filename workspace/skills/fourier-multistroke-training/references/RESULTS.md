## 4GiB 高精度档（通用全局细节强化）

- 容器上限：`.fbs` / `render.json` / `.fdraw` 解压总量均 **4GiB**；`max_curves=100000`。
- 流程：`run_train` → `refine_detail.py`（任意图同一套全局 pass）→
  `compile_best --nmax 16384 --epsilon 0.08 --max-curves 100000` → `pack_fdraw` → `verify_delivery`。
- Starry Night 实测：30,273 笔，0 填色，`.fbs` 1.26GB，`.fdraw` 145.9MB；
  2048 PSNR **19.2793** / SSIM **0.39824**，`verification.json` all_ok=true。
- 色彩校准后：2048 PSNR 19.1821 / SSIM 0.39808；饱和度 0.2945→0.3356（源图 0.3165），
  视觉更接近原作；`.fdraw` 146MB，verify all_ok。
- 通用性冒烟：Lvpi5 512，基础 23,311 笔 + 自动细节 2,668 笔，
  PSNR 19.3093 / SSIM 0.61217（25.4s 细节渲染）。
- 莫奈《日出·印象》柔化模式（1280×993）：soft preset base 25.882/0.5499 →
  +soft_atmosphere 26.8616/0.57725 → 轻细节 27.0851/0.58167 → clean 26.9254/0.57983 →
  细节下 soft glaze **27.8712/0.64135**（2048 训练渲染）；最终 `.fbs` 13,986 笔，
  2048 渲染 26.2889/0.5915，`.fbs` 252.7MB，`.fdraw` 28.8MB，verify all_ok。
- 麦田群鸦粗短笔画版（宽幅 2959×1417）：旧版 29,255 笔（1536 PSNR 19.6322 / SSIM 0.30121，
  2048 18.7014 / 0.23131）→ 增量 18,000 粗短笔（总 47,255 笔）→
  1536 **19.8423 / 0.31568**，2048 **18.9261 / 0.24088**；`.fbs` 1.70GB，`.fdraw` 187MB，verify all_ok。
- 向日葵低色差纹理版：1408 base 18,699 笔 → detail+texture 38,903 笔
  （`oil_texture=8000`，PSNR 25.1102 / SSIM 0.6228）→
  `clean_strokes` 去卷曲 34,929 笔（25.0221 / 0.61835）→
  `calibrate_color --sat-mul 1.10`（24.4022 / 0.61929）→
  4GiB 编译 2048 PSNR **23.9574** / SSIM **0.59805**，`.fbs` 317MB，`.fdraw` 37.3MB。
- 性能：30k 笔 4GiB 编译约 8min（峰值内存 ~10GB），2048 渲染约 3min。

## 已否决路线：strict single-curve

- 尝试过一条路径/一次 FFT（轮廓线稿、扫描线、螺旋、填色排线；N=16384/65536）。
- 结果：线稿 PSNR≈8.8、扫描线单曲线 PSNR≈14.8（条纹/块状），无法同时保颜色面与细节；
  17k 笔彩插 + 单曲线 + 0 填色的组合在当前 N cap 下不可行。
- 详细记录与产物：`training/single_fft/`（保留作反例，不再作为交付）。
